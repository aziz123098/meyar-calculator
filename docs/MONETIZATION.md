# Proposed monetization — not enabled

Start with a useful free calculator. Test demand for an optional one-time Pro unlock before introducing a subscription. A tentative price to test is SAR 19.99, subject to the available App Store price points. This is a product hypothesis, not a revenue forecast.

Possible Pro value: customized report headings, richer multi-result reports, saved report templates, and advanced history organization. The current implementation exposes its features freely for testing; it does not enforce any Pro restrictions.

Use StoreKit in-app purchase for the proposed iOS digital-feature unlock, with restoration and entitlement verification. Confirm current storefront-specific rules before implementation. A paid feature must have clear ongoing value before considering recurring subscriptions.

Apple Developer membership is generally USD 99/year, with regional pricing shown during enrollment. Store fees, taxes, refunds, and support costs reduce net proceeds.

Saudi compliance needs confirmation for the actual business activity. Apple's individual enrollment option does not establish an exemption from Saudi commercial requirements. Ministry of Commerce guidance on e-commerce discusses a commercial registration or an appropriate freelance document; verify whether the selected activity and document cover selling this app before activating sales. Do not assume any freelance document suffices or that a generic calculator requires a financial-services license merely because it estimates installments.
